## Specification Audit Note

The current status table follows the latest official numbering supplied for
SPEC-020 through SPEC-027.

Two earlier documents reused numbers that now belong to different
specifications:

- `Early Retention Loop` was previously called SPEC-021. It remains a planned
  seven-day onboarding and retention system and needs a new permanent number.
- `Public Launch Infrastructure` was previously called SPEC-022. Its Coming
  Soon, early-access, referral, DevLog, What's New, and sharing foundations are
  completed, but the specification needs a new permanent number.

The following major deliveries are recorded as product milestones rather than
numbered specifications:

- Product Update #1: economy, companies, bots, events, achievements, and daily
  quest foundations.
- Android and Capacitor application delivery.
- Five-language localization.
- Mobile interface and browser reliability work.
- Mentavio brand and logo integration.

These items must be reviewed before the next specification number is assigned,
so no previous requirement or completed feature disappears from the roadmap.

## Completed Specifications

### SPEC-020 - Beginner Onboarding

- Added a guided first session for new players.
- Made the first trade highly likely to succeed.
- Added an immediate token reward and first achievement.
- Added a result explanation so the player understands why the trade worked.
- Added a transition from the guided win to continued learning.
- Added first-session retention metrics and progression foundations.

### SPEC-021 - Platform Architecture

- Prepared one account system for multiple future Mentavio applications.
- Added a shared token wallet and game identifiers.
- Added global and game-specific achievement foundations.
- Added shared profile, progression, statistics, store, and notification
  architecture.
- Kept Trading Simulator as the first application without building future
  games prematurely.

### SPEC-022 - AI Mentor Landing

- Created the premium Mentavio landing page.
- Introduced Sophia as the AI decision mentor.
- Positioned trading as one application inside a broader decision-intelligence
  ecosystem.
- Added localized landing content in English, Russian, Hebrew, German, and
  French.
- Embedded the landing page in the Android application.
- Connected the landing page to the Trading Simulator.

## Planned Specifications

### SPEC-023 - AI Identity

Define Sophia's permanent identity, voice, behavior rules, safety boundaries,
visual presentation, and role across all Mentavio applications.

### SPEC-024 - Brand Identity

Create the complete Mentavio brand system: logo rules, typography, color
system, product naming, brand voice, and usage standards.

### SPEC-025 - Crowdfunding Landing

Create a public campaign page that explains the product, vision, development
stage, funding goals, rewards, and trust signals.

### SPEC-026 - Public Roadmap

Publish a clear product roadmap with completed, active, and planned milestones
that can be understood by users, testers, and potential supporters.

### SPEC-027 - Community & Beta Program

Prepare early-access registration, tester groups, feedback collection, referral
invites, community communication, and beta participation rewards.

## Update Policy

When a meaningful product update is completed:

1. Add the newest update at the top of `Product Update History`.
2. Add the date, user-facing changes, and related GitHub commit.
3. Update the specification table when a specification changes status.
4. Keep planned work separate from completed work.
5. Record product behavior and user-visible results, not only technical file
   changes.
